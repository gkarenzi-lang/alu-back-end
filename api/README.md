# alu-back-end

Back-end projects for ALU.

## api
Python scripts that gather data from the JSONPlaceholder REST API
(https://jsonplaceholder.typicode.com) for a given employee ID:

- `0-gather_data_from_an_API.py` - prints the employee's TODO list progress
- `1-export_to_CSV.py` - exports the employee's tasks to `USER_ID.csv`
- `2-export_to_JSON.py` - exports the employee's tasks to `USER_ID.json`
- `3-dictionary_of_list_of_dictionaries.py` - exports all employees' tasks to `todo_all_employees.json`

Usage: `./0-gather_data_from_an_API.py 2`
